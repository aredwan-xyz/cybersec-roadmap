# Checklist: Personal security checkup

About an hour, once. It covers the habits that stop most attacks on ordinary people. Lessons [2](../learn/02-protect-yourself.md) and [3](../learn/03-scams-and-phishing.md) explain why each one matters.

## Accounts

- [ ] Install a password manager (the one built into your phone or browser is fine to start).
- [ ] Change your email password to a long, unique one. Your email can reset every other account, so it comes first.
- [ ] Turn on multi-factor authentication (MFA) for email, banking and your main social accounts. Prefer an app, a passkey or a security key over text messages.
- [ ] Save your MFA backup codes somewhere safe and offline.
- [ ] Check your email address at [Have I Been Pwned](https://haveibeenpwned.com/) and change the password of any account listed in a breach.
- [ ] Replace any password you use on more than one site, starting with the most important accounts.
- [ ] Set up passkeys where your important accounts offer them.

## Devices

- [ ] Turn on automatic updates for your phone, computer and browser.
- [ ] Use a screen lock with a PIN of at least six digits, or a password.
- [ ] Turn on "Find my device" so you can lock or erase a lost phone or laptop.
- [ ] Remove apps and browser extensions you no longer use.
- [ ] Make sure disk encryption is on (FileVault on a Mac, BitLocker or Device Encryption on Windows; modern phones do it when a screen lock is set).

## Backups

- [ ] Back up your photos and documents automatically to a cloud service.
- [ ] Keep a second copy on an external drive that is not always plugged in.
- [ ] Restore one file from your backup to check that it actually works.

## Home network

- [ ] Change the router's default admin password.
- [ ] Use WPA2 or WPA3 for Wi-Fi with a long password.
- [ ] Update the router's firmware, or turn on automatic updates if it has them.

## Scams

- [ ] Agree a "check-in" rule with family: any urgent request for money gets a call back on a known number first.
- [ ] Learn your bank's real phone number and app, and never use contact details from a message you were sent.
- [ ] Know where to report scams in your country (for example the FTC in the US, the Canadian Anti-Fraud Centre in Canada, or Action Fraud in the UK).

## If something goes wrong

- [ ] Know the first three steps: change the password from a different, clean device; sign out of all sessions; turn on MFA.
- [ ] Write down your bank's fraud line where you can find it in a hurry.
