# Start here: cybersecurity from zero

Fourteen short lessons that explain how cybersecurity works, in plain English. You do not need any technical background. Each lesson takes about 15 minutes and ends with a three-question quiz and something safe to try.

Take them in order the first time. Later lessons build on words and ideas from earlier ones. If a word is new, the [glossary](glossary.md) explains it in one sentence.

## A note on safety and the law

Every hands-on task in this course uses your own devices and accounts, or practice sites built for learning. Testing someone else's system without written permission is illegal in most countries, even if you mean well. See [security and scope](../SECURITY.md).
